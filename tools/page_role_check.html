For each drawing set, Claude wrote down which pages it thinks play each role. The page finder is scored against these lists, so they need to be right. Please check them.

  1. Click a picture to see the page large.
  2. Mark every listed page Right or Wrong.
  3. If a page is missing, open it (in the list, or under "All pages") and use the Add to buttons.
  4. For main floor plans, write the level (e.g. Ground, Mezzanine, Level 1) when the job has more than one.
  5. Tick This set is checked. Answers save by themselves; you can stop and come back.
