# Subskill: boundary_resolution

- Classify boundary as external, ground-contact, roof void, corridor,
  adjacent tenancy/plant, or dynamic room-to-room from explicit geometry and
  notes.
- Boundary classification is independent of design-weather availability. Use
  selected design weather only for an outdoor temperature; leave temperature
  unresolved when no compatible profile is available.
- Require a cited or overridden temperature for fixed-adjacent conditions and
  both owners plus the existing gate for dynamic coupling.
- Do not substitute a generic indoor/outdoor temperature. Missing or
  conflicting boundary condition excludes only the affected surface.
