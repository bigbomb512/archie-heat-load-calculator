Method

From a PDF set to a defensible load.

  1. 01

    Read the set

    Plans, sections, elevations and specifications are triaged, rendered and read, so the calculation starts from the issued drawings rather than a re-typed summary.

  2. 02

    Build the envelope

    Review opaque constructions, U-values and room boundaries. Keep source references with each record before using it in the cooling model.

  3. 03

    Set the conditions

    Site weather, design days, occupancy and operating schedules are applied per zone, so the model reflects how the building is actually run.

  4. 04

    Calculate and cite

    Hourly sensible and latent loads are produced per room and per zone, each traceable to its inputs and marked draft, blocked or review-ready.

Evidence

A number you can put in front of a reviewer.

Load calculations get challenged. Archie keeps the chain intact, so when someone asks where a U-value or an occupancy figure came from, the answer is one click away rather than a memory of a meeting.

  • Source references kept alongside reviewed drawing facts
  • Unsupported values held as explicit exclusions, never quietly filled
  • Draft, blocked and review-ready states on every result
  • Comparison-report scaffolding for benchmark review
