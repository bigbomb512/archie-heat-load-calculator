# Reference rooms for Camel

Three simple rooms to enter in Camel, so Archie's draft can be compared with an independent tool (docs/draft_reference_rooms.md). Please run each as described and send the room loads by component, with the peak month and hour, for January 3 pm and the peak.

**Site and weather (all rooms):** Sydney (33.87°S, 151.21°E). Summer design 32 °C dry bulb with 23 °C wet bulb at 3 pm; inside 24 °C / 18 °C wet bulb. Clear sky, 21st of each month. No safety allowance; fan heat 3.2% of room sensible. These temperatures are synthetic test values, not AIRAH data.
