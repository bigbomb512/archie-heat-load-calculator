# Set 17 fixes (2026-11-14)

Set 17 is "PDF AI training -2" house 22008 (139a Burns Road, Turramurra): Basement/cellar, Ground and First floors.
Its first full run on Codex (2026-11-14, 14:31–15:25) gave 37.5 kW at 5 pm in February. That number is not usable:
"Driveway" (985.8 m², 17.8 kW) and "Timber Fence BDY m" (290.7 m², 5.2 kW) were counted as rooms; bedrooms were 1 m²
or missing; rooms were placed on the wrong floor; no window counted; the site read "Turra Lot".

Branch `set17-continue` (`set17-fixes` 0f43c53 and 4bb692b, then 271202f) changes the following. Codex wrote most of it; it was
reviewed, corrected and finished in Claude Code.

## What changed

| Problem | Change | Where |
|---|---|---|
| Site objects became rooms | Labels such as driveway, fence/boundary/BDY, site, lot, setback, paving never enter the room list or give a room area | `ai/room_inference.py` `plausible_room_label`, used by room inference, room use, the room proposal and traced rooms |
| Printed site/lot area taken as a room's | A printed area is a room's only if its text isn't a site/lot/land/driveway/landscape area and it is no larger than the level's footprint (else 500 m² for a house, 5000 m² otherwise) | `ai/room_inference.py` `_geometry_rows`; `ai/autonomous_tasks.py` `validate_room_size_reply` |
| "Tenancy area" refused for a one-room shop | Allowed when the question has one room or the room is the tenancy | `validate_room_size_reply` |
| Every room asked about on every plan | Rooms are asked about only on the plan of their own level (or the page they're printed on when their level is unknown) | `backend/autonomous_tasks_service.py` `_inferred_rooms_for_plan` |
| Missing house rooms | Numbered bedrooms kept apart ("Bedroom 3"), and house room words (master bedroom, ensuite, laundry, WIR, garage, family, entry, study, media, scullery, alfresco, ...) read — on a dwelling only, so a shop's "ENTRY" note isn't a room | `parse_room_label_item`, `HOUSE_ONLY_TERMS` |
| Compliance diagrams' labels | Floor-area and open-space diagram pages are skipped for room names, unless the plans name no rooms at all | `_cached_inferred_room_data` |
| AI's real room refused ("not in the room list") | A name printed on that plan page (drawing text, outside the title block), or quoted from it by the AI, is accepted | `ai/room_outline.py` `_allow_page_room` |
| 1 m² bedroom used as-is | Minimum plausible areas: bedroom 6 m², bathroom/ensuite/WC 2.5 m² (a conservative draft floor, not a code minimum); a smaller trace falls to the next area step (printed dimensions, then a scaled estimate), labelled | `room_outline.minimum_room_area` |
| No window load | The "WINDOW LIST / ID / W x H" schedule is read (28 windows on set 17). Windows not on a traced wall go to the nearest printed room label on the same plan (within 9 m, clearly nearest, not garage/outdoor/wet areas), with averaged sun and no wall area, labelled provisional. Any window still unplaced is reported and the result is marked an included-scope subtotal | `ai/house_windows.py`, `backend/house_windows_service.py`, `backend/ai_preliminary_service.py` |
| Site "Turra Lot" | The rule clue and the AI's address agree when the number and street match and one suburb is a cut-off start of the other | `ai/autonomous_tasks.py` `site_cross_check` |
| Codex time-outs on whole-floor outlines | A Codex time-out is now a `ProviderTimeout`; the outline is retried once with the plan image at most 1024 px (points scaled back), then left to the room-by-room area routes without tenancy clipping | `backend/ai_provider.py`, `backend/drawing_tasks_service.py` |
| AC and pool pumps as room equipment | On a house, air conditioners, pool pumps, hot-water units and unidentified one-letter tags get no room heat | `backend/equipment_catalogue_service.py` |
| Needed a second "Try again" | Set 17's drawing step stopped at the 8-round limit with work left; the limit is now 16 | `drawing_tasks_service.MAX_ROUNDS` |
| Wall legend not read | Dincel, brick cavity and stud wall legends on plan pages are listed for review; no U-value is set from them | `ai/construction_u_values.py` `plan_wall_legend` |
